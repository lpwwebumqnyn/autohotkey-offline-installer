## About

AutoHotkey is a free, open-source scripting language for Windows that automates repetitive tasks. Remap keyboard shortcuts, create text macros, automate mouse movements, and build GUI applications through a simple scripting language. With a large community and thousands of shared scripts, AutoHotkey can automate nearly any Windows task from one-line hotkey remaps to complex multi-application automation workflows.

## Common Problems & Limitations

- **Windows Only** — No macOS or Linux equivalent
- **Scripting Required** — Full power requires learning AutoHotkey scripting language
- **Version Differences** — AutoHotkey v1 and v2 have syntax differences; scripts may not be compatible
- **Antivirus Flags** — AutoHotkey scripts occasionally trigger antivirus false positives
